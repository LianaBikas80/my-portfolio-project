## 🇬🇧 English Version

This project is a personal portfolio designed and implemented to showcase my skills, projects, and professional path in web development. The focus of this project is to provide a smooth, modern, and responsive user experience.

### Key Features
- **Professional UX:** Responsive design compatible with all devices.
- **Dynamic Themes:** Full support for Dark Mode and Light Mode.
- **Localization:** Implemented localization to switch languages between Persian and English.
- **Admin Panel:** Authentication system for managing site content.
- **Modern Tech:** Utilizing modern React and Node.js architecture.

### Tech Stack
- **Frontend:** React, Vite, Tailwind CSS, Framer Motion
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Tools:** Git, GitHub

### Installation
1. Clone: `git clone https://github.com/LianaBikas80/my-portfolio-project.git`
2. Enter: `cd my-portfolio-project`
3. Install: `npm install`
4. Run: `npm run dev`
